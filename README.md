# Brighter Review

Independent study reviewer for Variable Life (VUL) and Traditional Life exam preparation.

- 50 verified questions per track
- randomized question and choice order
- 100% phase-mastery requirement
- complete answer review after every round
- installable on Android and iPhone as a Progressive Web App
- complete offline access after the first online visit

This is an unofficial independent study tool. It is not affiliated with or endorsed by Sun Life Grepa Financial, Inc.
